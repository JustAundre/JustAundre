## AI Disclaimer & Transparency

This disclaimer applies to **all** projects under this profile.

AI-assisted development is present *exclusively* in the following processes:

- Debugging (Fixing and understanding why an issue was present)
	- The generation of patches may be expected, but not before I have tried myself.
	- If a patch is AI-generated, it is **generally**, relatively small.
- Discovery (finding new tools, or concepts to utilize)
- Learning (understanding how a tool works or why a change was made)

Full scripts (including ones as small as 50 lines) will never be fully-generated using AI,
and changes suggested by AI will never be committed without thorough and full understanding of the code
(applies to the aforementioned possible AI-assisted hotfixes),
as I think of my work not only as a means to an end, but a form of the arts.
